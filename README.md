# Симулятор звезды

Стенд модели звезды для игры «Горизонт М31»: фотосфера (как видит глаз), жизнь поверхности (пятна, поле, нагрев), корона в ультрафиолете
(канал 17,1/17,4 нм), сценарные вспышка и корональный выброс, сверхновая. Корона сверяется сначала с Солнцем — по снимкам SDO/AIA 171
(страница «Ориентиры»), потом переносится на другие звёзды.

**Открыть:** https://arybashov.github.io/star-sim/ (нужен браузер с WebGL2 и плавающей точкой в целях отрисовки).
Локально — любой статический сервер из корня репозитория, например `python -m http.server`, затем http://localhost:8000/.

## Из чего складывается рисунок короны

1. **Поле.** Полюса пятен — погружённые магнитные заряды (поле 1/r²), заряды-изображения для поверхности источника (дальше поле
   открыто), диполь звезды.
2. **Нагрев у оснований.** Перемешивание поля конвекцией: F ∝ B²·v·tgθ/4π × доля площади концентраций поля; в тенях пятен — слабее.
3. **Газ в петле.** Для каждой точки — силовая линия; газ по законам RTV (T = 1400·(pL)^{1/3}), плотность с высотой — равновесие
   под тяжестью; открытые линии — разреженные и тёмные.
4. **Свет 17,4 нм.** n²·R(T), отклик канала — пик около 0,9 МК.
5. **Слои картинки.** Объём газа (петли по силовым линиям), мех (мелкий узор нагрева оснований вдоль силовых линий), магнитный
   ковёр (короткие петли спокойной поверхности по сети супергрануляции), протяжённая спокойная корона (петли RTV), мох (переходный
   слой у оснований горячих петель активных областей). Слои у поверхности берут нагрев спокойного Солнца (ковёр и слабое поле сети),
   петли активных областей рисует объём.
6. **Активные области.** Поток области — пятно (≈ 30 %, в тени 3 кГс) и факельная площадка вокруг.
7. **Край.** Холодное вещество хромосферы и спикул поглощает свет 17,1 нм: плотная часть — по измерениям AIA (край на ≈ 4 тыс. км),
   лес спикул — подгонка по профилю края SDO.
8. **Тон** — как у снимков AIA 171: √ яркости, белое — 7,3 медианы середины диска.

Честно: поле потенциальное (без токов и пересоединения), газ в равновесии (без нановспышек), отклик канала — приближение, яркость
относительная; поглощение у края и тон подогнаны по одному снимку SDO в браузерном качестве; вспышки и выбросы — сценарные.
